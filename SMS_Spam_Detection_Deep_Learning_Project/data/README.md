The training script downloads the UCI SMS Spam Collection dataset automatically.

Official dataset page:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

If automatic download fails, download the dataset manually and place the file named
`SMSSpamCollection` in this folder. It is a tab-separated file with the label in the
first column (`ham` or `spam`) and the message text in the second column.
